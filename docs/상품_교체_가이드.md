# 서플라이스타 상품 교체 가이드

이 사이트의 상품 정보는 `content/catalog.json` 한 파일에서 관리합니다. 실제 상품 이미지는 `public/products/` 폴더에 넣습니다.

## 가장 빠른 교체 방법

1. 새 상품 사진을 `public/products/상품-id.jpg`처럼 저장합니다.
2. `content/catalog.json`의 `products` 목록에서 기존 상품 한 묶음을 복사합니다.
3. 아래 항목만 바꿉니다.

| 항목 | 입력 예시 | 설명 |
| --- | --- | --- |
| `id` | `ricola-lemonmint-2pack` | 영문 소문자·숫자·하이픈만 사용하며 중복되면 안 됩니다. |
| `name` | `리콜라 레몬민트 허브캔디` | 화면에 표시되는 상품명입니다. |
| `brand` | `RICOLA` | 이미지가 없을 때 상품 카드에 크게 표시됩니다. |
| `category` | `snack` | `snack`, `drink`, `office`, `it` 중 하나입니다. |
| `price` | `24700` | 숫자만 입력합니다. 가격 상담 상품은 `null`입니다. |
| `unit` | `342g × 2개` | 규격이나 판매 단위입니다. |
| `badge` | `BEST` | 필요 없으면 `null`입니다. |
| `description` | `회의실에 두기 좋은 허브 캔디입니다.` | 상품 상세 팝업에 표시됩니다. |
| `image` | `/products/ricola-lemonmint-2pack.jpg` | 사진이 없으면 `null`로 둡니다. |
| `tone` | `lime` | 사진이 없을 때 사용하는 배경 스타일 이름입니다. |
| `featured` | `true` | 추천 상품 여부입니다. |
| `isNew` | `false` | 신상품 여부입니다. |

## 사진 권장 규격

- JPG, PNG 또는 WebP
- 정사각형에 가까운 비율
- 권장 크기: 1200 × 1200px 이상
- 흰색이나 밝은 단색 배경 권장
- 파일명에 공백과 한글을 사용하지 않는 것을 권장

사진이 없는 상품은 브랜드 타이포 카드로 자동 표시되며, 나중에 `image` 경로만 입력하면 실제 사진으로 전환됩니다.

## Codex에게 교체를 요청할 때

다음 자료를 한 번에 전달하면 가장 빠르게 반영할 수 있습니다.

- 상품명
- 브랜드
- 카테고리
- 판매가 또는 `견적 문의`
- 규격/판매 단위
- 짧은 설명
- 배지 문구(선택)
- 상품 사진
- 기존 상품 중 삭제하거나 숨길 항목

요청 예시: “첨부한 상품 8개로 카탈로그를 교체하고, 음료 카테고리의 기존 상품은 모두 내려줘. 가격은 부가세 포함이야.”

## 반영 전 확인

상품을 바꾼 뒤 `npm run validate:catalog`를 실행하면 중복 ID, 잘못된 분류, 누락된 이미지 경로를 확인할 수 있습니다. 최종 공개 전에는 상품명·가격·규격·사진의 일치 여부를 사람이 한 번 확인해야 합니다.
